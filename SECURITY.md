# Security Policy

## Scope

This repository contains a Claude skill: instructions and reference material
that guide Claude when driving the [latex-forge](https://github.com/thmsgo18/latex-forge)
CLI. Security reports are most relevant for `scripts/validate_skill.py` and
the [GitHub Actions workflow](.github/workflows/ci.yml).

## Reporting a Vulnerability

Please do not open a public issue for security vulnerabilities.

Instead, use GitHub's [private vulnerability reporting](https://github.com/thmsgo18/latex-forge-skill/security/advisories/new),
or email thomas.gourmelen@icloud.com with details and steps to reproduce.

You should expect an initial response within a few days.
